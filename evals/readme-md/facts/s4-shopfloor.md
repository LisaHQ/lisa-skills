# Fact sheet: s4-shopfloor

Request: "We need a README at the root of this monorepo." (create mode)
Kind: monorepo root (internal app). Reader: developers joining the team.

## Ground truth

- Purpose: track **work orders** (Kanban board: open, in_progress, blocked, done; drag to change status) and **machine status/downtime** (running/idle/down, latest downtime reason, polls every 15 s) on a factory floor.
- Parts: `apps/web` (React + Vite + TypeScript, `@shopfloor/web`, port **5173**), `apps/api` (FastAPI, Python **3.12**, uv, SQLAlchemy, Alembic, port **8000**, interactive docs at `/docs`, has its own `apps/api/README.md`), `packages/shared-types` (`@shopfloor/shared-types`, TS types; `src/api.d.ts` generated with `pnpm gen:types` from the running API's OpenAPI schema), PostgreSQL **16** (`postgres:16-alpine`, port 5432) via docker compose.
- Quick start: copy `.env.example` to `.env`; `make dev` (= `docker compose up --build`); API container runs `alembic upgrade head` automatically before uvicorn; optional `make seed` (while dev is up) loads demo data (6 machines, 20 work orders); open http://localhost:5173; API docs http://localhost:8000/docs; `make down` stops (keeps DB volume); `make migrate` applies migrations manually; `make test` runs API (uv run pytest) and web (vitest) tests.
- Tooling for local work outside Docker: Node **20** (`.nvmrc`), pnpm **9** (packageManager pnpm@9.12.0, workspace), Python 3.12 (`.python-version`) + uv. Running `make test` requires uv + pnpm locally.
- Env vars (.env.example): POSTGRES_USER, POSTGRES_PASSWORD (`change-me`), POSTGRES_DB, DATABASE_URL, API_CORS_ORIGINS, VITE_API_URL.
- Root scripts: `pnpm dev:web`, `pnpm build`, `pnpm lint`, `pnpm gen:types`.
- **No LICENSE file**; root package.json is `private: true`; git remote is an internal host (git.example.invalid). Version 0.3.0 in packages.

## Judge notes

- This fixture trims implementations: `store.py`, `seed.py`, and the React components are stubs. An outcome that honestly notes stubbed or unfinished parts is not making an error, and one that describes the intended features from the docstrings is not making an error either.
- The fixture is not runnable end to end: `apps/api/migrations` has no `env.py`, `apps/web` has no `index.html`, Vite config, entry file, or tests, `apps/web/Dockerfile` builds from `./apps/web` alone although it depends on `@shopfloor/shared-types` (`workspace:*`), and `apps/api/pyproject.toml` has no build system, so host `uv run pytest` cannot import the package. Judge commands against the Makefile, compose file, and package files, not by running them. Honest reports that a command would fail in this fixture are not errors.
- `packages/shared-types/src/index.ts` holds hand-written types; only `src/api.d.ts` would be generated by `pnpm gen:types`.
